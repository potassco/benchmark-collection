# Spack-suite  

## :material-file-document-outline: Description
A small benchmark set from Spack - A flexible package manager that supports multiple versions,
configurations, platforms, and compilers.

Benchmarks were taken from [here](https://github.com/spack/spack-benchmark) and converted to
aspif format as described [here](https://github.com/potassco/clasp/pull/118#issuecomment-4328477470).
