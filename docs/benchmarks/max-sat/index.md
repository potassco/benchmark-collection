# Weighted MaxSAT  

## :material-file-document-outline: Description
A subset of the weighted instances from the exact track of the MaxSAT Evaluation 2023.
From the original 558 instances, this set only has the 515 instances with weights < `2^32`.

The benchmarks are in the new standarized MaxSat format, which is not yet supported in
clasp-3.4.x/clingo-5.8.x. They can be converted to the old (pre 2022) format via
[std_wcnf](https://bitbucket.org/fbacchus/maxsat_benchmarks_code_base/src/master/#markdown-header-std_wcnf)
