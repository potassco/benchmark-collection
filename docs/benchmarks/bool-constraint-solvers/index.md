# Benchmark Set for Boolean Constraint Solvers

## :material-file-document-outline: Description
A set of ASP and SAT benchmarks selected from various competitions using the
[Benchmark-Set-Selection-Tool](https://github.com/potassco/benchmark-set-selection-tool). 
For a full description see
[Robust Benchmark Set Selection for Boolean Constraint Solvers](https://www.cs.uni-potsdam.de/wv/publications/DBLP_conf/lion/HoosKSS13.pdf).
