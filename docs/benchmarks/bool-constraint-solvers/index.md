# Benchmark Set for Boolean Constraint Solvers

### 📖 Description
A set of ASP and SAT benchmarks selected from various competitions. 
For a full description see
[Robust Benchmark Set Selection for Boolean Constraint Solvers](https://www.cs.uni-potsdam.de/wv/publications/DBLP_conf/lion/HoosKSS13.pdf).

### ⚙️ Technical Details
* **Type:** Decision
* **Format:** Smodels, CNF (compressed)
* **Tested With:** clingo

### 📊 Instances
* **Generation:** Via selection tool
* **Details:** See paper
